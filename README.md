
# AI-Driven Drug Discovery

Machine learning-based identification and prioritisation of potential small-molecule drug candidates using bioactivity data, molecular descriptors and ADMET profiling.

## Overview

An end-to-end computational drug discovery project focused on predicting the biological activity of chemical compounds against cancer-associated therapeutic targets.

The initial investigation focuses on Epidermal Growth Factor Receptor (EGFR), using experimentally reported bioactivity data from ChEMBL.

## Research Focus

| Parameter | Description |
|---|---|
| Domain | Computational Drug Discovery |
| Therapeutic Area | Oncology |
| Target | EGFR |
| ChEMBL Target ID | CHEMBL203 |
| Data Source | ChEMBL |

## Pipeline

- Target selection and bioactivity data collection
- Data curation and molecular standardisation
- Molecular descriptor and fingerprint generation
- Bioactivity prediction using machine learning
- Model validation and performance evaluation
- Drug-likeness and ADMET profiling
- Candidate ranking and prioritisation
- Interactive molecular screening interface

## Tech Stack

**Languages:** Python

**Data Analysis:** Pandas, NumPy, Matplotlib, Seaborn

**Cheminformatics:** RDKit, ChEMBL API

**Machine Learning:** Scikit-learn, XGBoost

**Visualisation & Interface:** Plotly, Streamlit
